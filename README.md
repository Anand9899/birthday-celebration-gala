# 🎂 The Grand Birthday Celebration Gala

A full-stack interactive 3D birthday celebration web application built with Node.js, Express, Web Audio API, Canvas Pyrotechnics, and Vanilla CSS.

![Birthday Gala](public/polaroid-1.jpg)

---

## ✨ Features

1. **🎵 Multi-Track Birthday Jukebox**:
   - Web Audio & MP3 synthesizer with 4 distinct tracks: *Grand Gala*, *Upbeat Pop*, *Bollywood Nostalgia ("Baar Baar Din Yeh Aaye")*, and *Peaceful Lofi Piano*.
2. **🎨 Live Theme Switcher**:
   - 4 luxury theme presets: *Royal Gold*, *Rose Gold*, *Cosmic Neon*, and *Emerald Gala*.
3. **🎂 Dynamic 3D Cake with Age Numeral Candles**:
   - Interactive 3D birthday cake with realistic flicking flames, blow-out physics with smoke puff, cut-the-cake ceremony, and customizable dual number candles (e.g. 21, 25).
4. **📥 Download Birthday Souvenir Poster (PNG)**:
   - High-resolution (600x750) greeting card canvas generation with the celebrant's name, age, heartfelt quote, and date, ready for instant download and social sharing.
5. **🎈 Balloon Pop 30-Second Arcade Challenge**:
   - Real-time mini-game with floating festive balloons, combo score multipliers, audio popping effects, and local high-score tracking.
6. **🎙️ Voice Note / Audio Wishes**:
   - In-browser microphone voice recorder (MediaRecorder API) to record and post voice wishes with interactive playback pills on the guestbook wall.
7. **🎡 Interactive Spin The Birthday Wheel**:
   - Canvas-rendered 8-slice fortune wheel with deceleration physics, slice-ticking sounds, and victory confetti blasts.
8. **🤖 AI / Smart Birthday Wish & Shayari Generator**:
   - Instant personalized wish suggestions based on relationship (Friend, Sister, Brother, Love, Colleague) and tone (Emotional, Funny Roasting, Hindi Shayari, Short).
9. **💌 Live Guestbook & RSVP**:
   - Real-time guestbook wall with likes, custom emoji avatars, and RSVP attendee counter.
10. **🎆 Canvas Pyrotechnics & Confetti**:
    - Dual canvas engine with realistic multi-color fireworks, golden fairy dust, and confetti cascades.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v16 or higher)
- npm (installed with Node.js)

### Installation
```bash
# Clone the repository
git clone https://github.com/<your-username>/<repo-name>.git

# Navigate to the project folder
cd "Birthday celibration"

# Install dependencies
npm install

# Start the local server
node server.js
```

Open your browser and visit:
```
http://localhost:3000
```

## 🛠️ Tech Stack
- **Backend**: Node.js, Express, Multer (file uploads)
- **Frontend**: HTML5, Vanilla CSS3 (Custom Design System, Glassmorphism, 3D transforms), JavaScript (ES6+)
- **Audio**: Web Audio API (Synthesizers & sound effects) + HTML5 Audio
- **Graphics**: HTML5 Canvas (Fireworks, Confetti, Fortune Wheel, Poster Generator), SVG (3D Layered Cake & Flame Animation)
